# ADR-006 — Google Stitch design integration

- **Status:** Accepted for design exploration only
- **Date:** 2026-08-16
- **Related issue:** [#27](https://github.com/Neel2667/universal-OS/issues/27)

Google Stitch may generate visual concepts and journey explorations. It is not a source of trusted system code, boot behavior, service policy, accessibility completeness, asset licensing, or hardware claims.

A selected concept enters UniversalOS only after it has explicit design tokens, normal/focus/loading/offline/error/recovery/accessibility states, service contract mapping, performance evidence, and asset/source review.
